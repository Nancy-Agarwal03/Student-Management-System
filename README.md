# Student Management System

A Python-based Student Management System designed to simplify and organize student record management. The project provides a structured way to store, manage, update, and retrieve student information efficiently.

## Features

- **Add Student:** Register new student records.
- **View Students:** Display stored student information.
- **Search Student:** Find records using student details.
- **Update Records:** Modify existing student information.
- **Delete Student:** Remove student records when required.
- **Data Management:** Maintain organized student records.

## Technologies Used

- Python
- MySQL
- SQL
- Libraries like: Streamlit, Pandas, Matplotlib

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
```

2. Navigate to the project directory:

```bash
cd Student-Management-System
```

3. Install the required dependencies:

```bash
pip install -r requirements.txt
```

4. Configure your database connection.

5. Run the application:

```bash
python main.py
```
